# TRACE Roadmap

## Round 3 Commitments (Planned — Not Implemented)

1. **Readiness Verification**
   Automated pre-handover checks and sign-off gates verifying evidence coverage, resolved contradictions, and owner assignments before a departure is finalized.

2. **Living Handover**
   Continuous post-handover sync that surfaces newly merged commits, resolved issues, and updated decisions after a handover is shared.

3. **Continuity Graph**
   Interactive cross-project knowledge and dependency graph linking people, modules, decisions, and handovers over time.

## Planned Integrations (Not Implemented)

- Google Drive document sync
- Slack workspace channel import
- Jira issue and sprint import
- Notion knowledge base sync
- Private GitHub repositories via OAuth
- OCR for scanned PDFs
